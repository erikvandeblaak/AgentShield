# AgentShield brand masters

Original artwork for AgentShield (c) Erik van de Blaak, vandeblaak.com.

- `app-icon.svg` - 1024x1024 app icon with background. Generate the Tauri icon set with `npx tauri icon brand/app-icon.svg`.
- `glyph.svg` - full-colour shield glyph (favicon, small sizes).
- `logo-mono.svg` - monochrome outline glyph (uses `currentColor`; tray / template icon).
- `logo-dark-bg.svg`, `logo-light-bg.svg` - glyph + wordmark for dark and light backgrounds.

Motif: a geometric shield holding a scanning lens (observation) grounded by a single circuit trace (the local machine).
